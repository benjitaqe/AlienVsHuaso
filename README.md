Instrucciones de descarga y ejecución :D
-----------------------------------------
Ingresar al repositorio oficial de GitHub mediante el enlace proporcionado.
Ubicar la sección Releases, si la versión ejecutable está publicada allí, o acceder a la carpeta donde se encuentre disponible la versión compilada.
Descargar el archivo comprimido del videojuego en formato ZIP.
Extraer todo el contenido del archivo ZIP en una carpeta del computador.
Ingresar a la carpeta extraída.
Localizar el archivo ejecutable del videojuego (.exe).
Ejecutar el archivo para iniciar Huaso vs. Alien.
